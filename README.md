# Boon-UI

The agent-generated UI layer for **Boon** — a personal knowledge device with **no fixed apps**.

The agent composes every interface on demand: ask for email, get an email reader composed in real time; ask for a PDF, get a viewer; ask for a diagram, get one drawn — adapted to its reader and to whatever hardware it runs on. No installed apps; every function is a generation.

**Target hardware:** any Android phone with sufficient compute (open reference target), a bench-built dev kit (in design), and a book-foldable production concept — a hardcover that opens to a two-page spread: your text page + the agent-generated facing illustration.
